# Banco de Memoria

Este directorio conserva contexto verificable para contribuidores y agentes. Cada afirmacion debe enlazar archivos del repositorio o resultados de validacion registrados.

## Regla de evidencia

- No afirmar funcionalidades, clientes, objetivos de negocio, despliegues o rendimiento sin una fuente en el repositorio.
- No crear hojas de ruta. Registrar solo gaps observados y prioridades condicionadas por codigo, pruebas, configuracion o documentacion existentes.
- Actualizar la nota afectada en el mismo cambio que modifique el hecho que documenta.

## Indice

- `01-producto.md`: alcance observable y flujo de datos.
- `02-stack.md`: lenguajes, frameworks, infraestructura y dependencias.
- `03-estado-actual.md`: comportamiento validado, gaps observados y prioridades basadas en evidencia.
